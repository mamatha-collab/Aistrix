What is Aistrix?

Aistrix is an AI workflow platform that lets businesses build, chain, and automate AI-powered tools without writing code. It sits between generic AI chat (ChatGPT) and expensive enterprise automation (Salesforce Einstein) — giving SMBs a focused, context-aware AI layer for their real daily work.

Human Approval Steps

New Feature

Approval gates pause a workflow at a specific step and require a human to review or approve the AI output before the workflow continues. Critical for real business use cases where AI output must not go out unchecked.

✋ Needs Approval

Shows the previous step's output. Two buttons: Approve & Continue (passes output as-is) or Reject & Stop (ends the workflow with an optional reason).

Use case: Legal must approve a contract draft before it's sent.

✏️ Edit Before Sending

Shows the previous output in an editable textarea. Human can make changes. Confirm & Continue passes the edited text to the next step.

Use case: Sales rep edits AI-drafted email before it passes to the send step.

👤 Assign to Teammate

Shows output, email address field, and optional note. Generates a pre-filled mailto link. Human then approves to continue or rejects to stop.

Use case: Route AI-generated invoice to finance team for sign-off.

Workflow Triggers

Beyond manual runs, workflows can be triggered automatically. Two trigger types are live.

Live

⏰ Schedule Trigger

Access via: ⏰ icon on any workflow card. Set a frequency (daily / weekly), a UTC hour, and a seed input for the first step. The backend runs the full workflow headless — results go to Run History and fire the integration webhook if configured.

Requires a cron job calling POST /cron/run-schedules every minute with the X-Cron-Secret header.

Live

🔗 Webhook / API Trigger

Access via: 🔗 icon on any workflow card. Generate a unique UUID-based URL. POST to it from Zapier, Make, your own code, or any HTTP client. The request body becomes the first step's input. Approval gate steps are skipped in headless runs.

Revoke and regenerate the URL at any time. Anyone with the URL can trigger the workflow — treat it like a password.

Webhook request format

POST https://your-api.aistrix.app/webhooks/{token} Content-Type: application/json {"input": "Your trigger input here"}

Knowledge Vault

New Feature

A shared, persistent knowledge library that auto-injects into every AI App run and every Workflow step. Eliminates the need to re-explain your business to the AI each time.

📄 Documents

SOPs, onboarding guides, handbooks, internal wikis. Paste text or upload .txt / .md / .csv (max 2MB).

❓ FAQs

Support answers, common questions. The AI uses these to give consistent answers across all apps.

📋 Policies

HR policies, compliance rules, legal disclaimers. Ensures AI output stays compliant.

📦 Product Info

Features, pricing, roadmap. Lets sales and support apps reference accurate product information.

🌐 URL / Page

Paste a URL — the system fetches and stores the page content.

Active / Inactive toggle

Each item can be disabled without deleting it. Inactive items are excluded from injection immediately.

Business Perspective

Target market

SMBs with 5–200 employees in Sales, HR, Finance, Customer Support, and Marketing. Teams spending hours on repetitive document generation, email drafting, and research.

Competitive position

Below enterprise tools (Salesforce Einstein, Microsoft Copilot) in price and complexity. Above generic chat (ChatGPT) in business context and automation depth.

Primary value proposition

Context-aware AI that knows your business. The Knowledge Vault is the key differentiator — it makes Aistrix feel like a company AI, not a generic chatbot.

Monetisation levers

Daily credit limit nudges upgrades. Per-seat team plan for collaboration. API access tier for developers. Marketplace revenue share on premium templates.

Features Added — Needs Further Development

Schedule Trigger
UI and backend complete. Needs: (1) A cron job set up on the server calling /cron/run-schedules every minute. (2) Monthly schedule frequency option. (3) "Next run in X hours" live countdown in the UI.
Webhook Trigger
Frontend + backend complete. Needs: (1) Add webhook_token column to flows table (SQL migration provided). (2) Webhook run logs separate from manual run history. (3) Secret header auth option (HMAC) for security-conscious customers.
Knowledge Vault
UI complete. Needs: (1) Supabase SQL migration (table + RLS). (2) URL fetching backend endpoint. (3) Character count display. (4) Injection token-limit guard — if total vault content exceeds model context, truncate oldest items first.

Recommendations — Reaching 1,000 Users

The platform is technically strong. The gap to 1k users is distribution, activation, and retention — not features.

1

5-minute onboarding flow with a guaranteed win

After signup, walk new users through: install one Quick Start template → run it → see output. First run = hook. Every extra click before it = churn risk.

2

Industry-specific landing pages with pre-filled demos

aistrix.app/for/sales — loads with a Lead Qualifier workflow already populated, showing AI output for a fictional prospect. High-converting for paid ads and organic search.

3

Weekly workflow digest email

Every Monday: "Here's what your AI did last week — 12 workflows ran, saved ~4.5 hours." This is the single most powerful retention mechanism. Users who don't return lose habit.

4

Slack / Teams bot integration

"/run [workflow name] [input]" in Slack. Eliminates the need to open a browser. The biggest competitor to Aistrix is the habit of opening ChatGPT directly — meet users where they are.

5

Team referral / invite loop

When a user shares a workflow with a teammate, the teammate gets a magic-link invite. First-run is pre-populated with the shared workflow. Every collaboration becomes a distribution event.

6

Marketplace with creator revenue share

Let power users publish premium app and workflow templates for $5–$20. Platform takes 30%. Creates incentive for creators to market Aistrix — a self-funding growth loop.

7

"Saved hours" metric on the dashboard

Show: "Your AI has saved you ~12.3 hours this month." Calculated from run count × average task time. Makes ROI visceral and shareable — drives organic social sharing.

8

Public workflow gallery with search

Community-built workflows indexed by search engines. "AI workflow for resume screening" → Aistrix gallery → one-click install. Organic SEO acquisition with no paid budget.

Intelligence Roadmap — Smarter Workflows

Current problem: Running "What is 1+1?" through the same AI App 10 times gives 10 slightly different answers, costs 10 API calls, and fills run history with noise. Repeated scheduled runs feel redundant when inputs don't change.
A

Input hash deduplication

Before running any step: hash the (system_prompt + input). Check the last N results for a matching hash. If found within 24 hours, return the cached result instantly without an API call. Shows "(cached)" badge. Saves credits and eliminates redundant outputs.

B

Workflow memory evolution

The "Workflow mind" already extracts facts from each run. Next step: surface a "Memory health" panel showing what the workflow has learned over time. Let users mark facts as permanent ("always use these") vs. ephemeral. Permanent facts never need re-inferring.

C

Smart model routing

The /select-model endpoint already picks a model per task. Extend it: simple factual questions → Haiku (cheap, fast). Complex reasoning → Sonnet. Add a "cost estimate" shown before the user clicks Run so they can choose.

D

Output diff on repeated scheduled runs

When a scheduled workflow runs twice with similar inputs, show a diff: "What changed since last Monday?" Surfaces the delta rather than the full output. Analysts and ops teams care about changes, not repetition.

E

Confidence scoring + "ask me first" mode

After each run, the AI rates its own confidence (1–5). Low-confidence outputs automatically insert a soft approval gate: "I'm not sure about this — do you want to review before continuing?" Only interrupts when needed.

F

Cross-workflow learning

If users consistently edit AI output to add a formal sign-off — learn this as a vault fact. Surface it: "We noticed you keep making this edit — want to add it to your Knowledge Vault?" Closes the human-AI feedback loop.

Bottom line: Aistrix already has a strong technical foundation. The path to 1k users runs through (1) activation — guarantee a first win in 5 minutes, (2) retention — weekly email digest and Slack bot, and (3) distribution — team invites and a searchable public gallery. Intelligence improvements (caching, memory, diffs) reduce friction for power users and drive the "this thing actually knows my business" moment that makes users stay.
